# Jane Street protocol emulator ASIC competition

Work in progress for the [Jane Street protocol emulator ASIC
competition](https://blog.janestreet.com/protocol-emulator-asic-competition/):
an open-source protocol emulator ASIC for IHP 130 nm CMOS5L on a Tiny Tapeout
8x4 tile, due 18 January 2027.

The architecture is being chosen now. Details will go here.
